# Component Inventory

Generated by `bun run inventory`. Do not edit by hand.

Rules:

1. Check this file before creating a component.
2. Reuse or extend an existing component before adding a new one.
3. Removing code is preferred to adding code.
4. If variants are needed, keep them in one plural file with named exports and no default export.
5. Full apps go under `components/apps`; reusable app chunks go under `components/sections`; placement goes under `components/layouts`; primitives go under `components/ui`.

This committed seed exists so agents have a map before the first local pre-commit regeneration.
