# Edgerun Build Log

This build log is not generated by an external CMS and is not served by a third
party stack. It is served from the same checkout used by the platform itself, via
`edgerun-server`.

The page you are reading is part of a single deployment surface that also hosts:

- production email workflows,
- DNS and HTTPS entry points,
- webmail surface,
- public crate/code explorer,
- this exact release log.

That shape is deliberate: the log should describe what already moves the real
service, not a separate “marketing deployment.”

## Current platform achievements

- Identity-first admission model with explicit audit evidence in this surface.
- Dashboard surfaces for build log, source, mail, and apps share one interface
  and one runtime projection model.
- Status, chat hooks, and source visibility are served from the same deployed binary and config flow.
- Browser app metadata is driven by `BrowserApp` config and surfaced in the app workspace.
- Feature boundaries are explicit: only selected crates and paths are exposed by
  release metadata and policy.

## Where to look next

Posts in this log are used to document public-facing capabilities as they become
reliable enough for day-to-day use. Each entry is intended to connect to a real
code path and a real commit.
