# บันทึกการสร้าง EdgeRun

เว็บนี้ถูกเสิร์ฟโดย `edgerun-server` จากเช็กเอาต์ซอร์สโค้ดของ Edgerun โดยตรง ไม่มีเว็บสแตกภายนอก ไม่มีขั้นตอน build แยก และไม่มีชั้น authentication เพิ่มเติม.
